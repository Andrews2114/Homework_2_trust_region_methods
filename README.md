# MATH-329 Homework 2 -- Trust-region methods for real phase retrieval (Group S)

Python code and LaTeX report for Homework 2 of MATH-329 *Continuous Optimization*.
Everything is reproducible with **one command**: it runs the tests, the derivative checks and all
experiments, then writes every figure and every number quoted in the report to `results/`.
The report reads those files, so code, results and report always agree.

## 1. What this project does

We minimise the (non-convex) real phase-retrieval cost

    f(x) = 1/(4n) || (Ax)^2 - y^2 ||^2        (entrywise squares)

with n = 200, m = 6n = 1200, noise sigma = 1e-3 (the instance of the handout, `seed = 0`), and compare:

* **TR-tCG**: a trust-region method whose subproblems are solved by truncated conjugate gradients
  (Steihaug-Toint), using only Hessian-vector products;
* **GD**: gradient descent with Armijo backtracking (baseline).

Error is measured by the sign-invariant relative error `e(x) = min(||x - x_true||, ||x + x_true||) / ||x_true||`,
because `x` and `-x` give the same measurements.

## 4. Setup

Requirements: Python 3 (developed with 3.12) and a LaTeX distribution with `pdflatex`
(packages used: amsmath, amssymb, mathtools, graphicx, booktabs, xspace, fancyhdr, array, microtype,
hyperref, geometry; all in TeX Live / MiKTeX).

    # optional but recommended: a virtual environment
    python3 -m venv .venv
    source .venv/bin/activate          # Windows: .venv\Scripts\activate

    pip install -r requirements.txt    # numpy, matplotlib

## 5. Run

Run from the folder `code/` (the script writes into `../results/`):

    cd code
    python main.py

It takes about 30 seconds on one CPU core (most of it is gradient descent, which needs ~14,000 iterations).
It prints a short summary, e.g. `tests: 19/19 passed`, the TR-tCG and GD iteration/product/time counts and the
multi-start result.

Then compile the report (from the repository root; run it twice so references settle):

    cd ..
    pdflatex S.tex
    pdflatex S.tex

**Order matters:** `S.tex` needs `results/` to exist, so always run `main.py` before compiling.
Re-running `main.py` regenerates all numbers; recompile afterwards so `S.pdf` matches. Wall-clock times vary
slightly from machine to machine and run to run; iteration counts, product counts and errors are deterministic.

To run only the tests:

    cd code
    python tests.py                    # prints PASS/FAIL for each test

## 6. Configuration

All experiment parameters are at the top of `code/main.py` and are written to `results/numbers.tex`, so the
report always shows the values actually used:

| Parameter | Value | Meaning |
|---|---|---|
| `N, M_FACTOR, SIGMA, SEED` | 200, 6, 1e-3, 0 | problem size, m = 6n, noise level, seed of the instance |
| `GRADTOL` | 1e-8 | stopping criterion `||grad f|| <= GRADTOL` for both methods |
| `DELTA0, DELTA_BAR` | 1, 100 | initial and maximal trust-region radius |
| `RHO_PRIME` | 0.1 | step accepted iff rho > 0.1 |
| `KAPPA, THETA` | 0.1, 1 | tCG stops when `||r|| <= ||g|| min(kappa, ||g||^theta)` |
| `N_STARTS` | 10 | extra random starting points for the robustness experiment |
| `GROUP_ID` | `S` | shown in the report header |

The group member names are set in `S.tex` (macro `\groupmembers`).

## 7. What `main.py` produces

1. **Tests** (`tests.py`): 19 checks with known answers; writes `tests_table.tex` and `test_log.txt`.
2. **TR-tCG test statistics** for Question 2 (iterations, rejected steps, negative-curvature exits, ...).
3. **Derivative checks** (Question 3): Taylor-remainder plots (expected slopes 2 and 3), agreement with the dense
   Hessian, timing of the matrix-free Hessian-vector product versus the dense Hessian.
4. **TR-tCG and GD on the instance** (Question 4): same `x0`, same stopping rule; cost counted in products with
   `A` or `A^T` and in wall-clock time; figures `fig_trtcg.pdf` and `fig_comparison.pdf`.
5. **Robustness**: both methods from `N_STARTS` other random starting points.
6. **Conditioning** of `A^T A` and of the Hessian at the solution (used in the discussion of Question 5).
7. `numbers.tex` with all of the above as LaTeX macros.

## 8. Main results (instance of the handout)

| | iterations | products with A, A^T | final e(x) |
|---|---|---|---|
| TR-tCG | 17 | 218 | 2.35e-3 |
| GD + Armijo | 13,839 | 41,517 | 2.35e-3 |

Both reach the same noise floor (the minimiser of `f` is not exactly `x_true` because of the noise).
TR-tCG converges to `-x_true`, which is equivalent to `+x_true` for this problem.
See the report for the full discussion.

## 9. Troubleshooting

* `ModuleNotFoundError: numpy` / `matplotlib`: activate the virtual environment and run `pip install -r requirements.txt`.
* LaTeX error `File 'results/numbers.tex' not found`: run `python main.py` first, and compile from the repository root.
* Report shows old numbers: re-run `python main.py`, then `pdflatex S.tex` twice.
* No display needed: figures are written with the non-interactive Matplotlib backend (`Agg`).
